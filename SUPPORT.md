# Support

## Start here

1. Update to the latest released Storm Detector version in HACS.
2. Restart Home Assistant after an integration update.
3. Read the README troubleshooting and privacy sections.
4. Check the Storm Detector entities and `source_status`, `degradation_reasons`, `last_error`, and `is_stale` attributes.

## Where to ask

- Reproducible bugs: use the [bug report template](https://github.com/petrvnk/storm-detector/issues/new?template=bug_report.yml).
- Feature proposals: use the [feature request template](https://github.com/petrvnk/storm-detector/issues/new?template=feature_request.yml).
- Security vulnerabilities: follow [`SECURITY.md`](SECURITY.md); do not disclose them in a public issue.

## Information to include

- Home Assistant and Storm Detector versions;
- installation method;
- expected and actual behavior;
- safe reproduction steps;
- reviewed Home Assistant diagnostics when relevant.

Remove tokens, exact home coordinates, addresses, private entity IDs, personal names, and unrelated logs before posting. Storm Detector is maintained on a best-effort basis; there is no guaranteed response time or service-level agreement.

Questions about RainViewer or a lightning provider's own availability, accounts, or upstream data belong with that provider unless Storm Detector handles the response incorrectly.
